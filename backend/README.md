# Backend

Đây là nơi lưu trữ mã PHP backend của dự án.

Hiện tại, phần backend gốc đang còn nằm ở thư mục gốc của project. Bạn có thể di chuyển dần các thư mục sau vào đây:

- app/
- config/
- core/
- public/
- routes.php
- composer.json
- composer.lock
- vendor/

Lưu ý: sau khi di chuyển, cần cập nhật lại đường dẫn import và cấu hình nếu có.
