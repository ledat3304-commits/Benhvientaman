# Admin

Thư mục này dành cho phần quản trị hệ thống.

Bạn có thể lựa chọn một trong hai cách:

1. Giữ admin trong frontend React hiện tại
2. Tách riêng admin thành một app riêng để dễ quản lý

Ví dụ các mục quản trị có thể include:

- Dashboard
- Quản lý bác sĩ
- Quản lý bệnh nhân
- Quản lý dịch vụ
- Quản lý thuốc
- Quản lý lịch hẹn
